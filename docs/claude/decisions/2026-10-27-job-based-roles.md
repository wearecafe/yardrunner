# Eleven job-based roles, several per user

Status: confirmed
Date: 2026-10-27
Area: Access
Decided by: Jon Moore

**Decision:** Roles: Owner, Admin, Sales, Rental desk, Yard crew, Dispatcher, Driver, Purchasing & inventory, Accounts, Service tech, Time & attendance only. A user can hold several; access is the union. Every role except Owner and Admin is scoped to assigned yards. Staff became Sales; Order picker became Yard crew.

**Turned down:** The old Owner, Admin, Staff and Order picker set.
