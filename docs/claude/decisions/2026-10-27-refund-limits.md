# Refund limits per role, with on-the-spot approval

Status: confirmed
Date: 2026-10-27
Area: Access
Decided by: Jon Moore

**Decision:** The tenant sets a refund limit per role. A user with several roles gets the highest. Above it, a user with Refund above limit approves on the spot, and both are logged.
