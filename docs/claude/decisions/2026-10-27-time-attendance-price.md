# Time and attendance is $5 CAD per tracked person a month

Status: confirmed
Date: 2026-10-27
Area: Billing
Decided by: Jon Moore

**Decision:** Billed per user set up as an employee with Clocks in on, whose employment hasn't ended and whose user is active. Users who aren't employees aren't billed.

**Source:** `docs/claude/commerce-data-model.md` → Decisions (Time & attendance billing); `docs/claude/modules/billing.md`.
